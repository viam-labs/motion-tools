# Documentation site

`docs/` is a standalone Astro Starlight site (own `package.json` and lockfile; run pnpm commands from `docs/`) published to https://viamrobotics.github.io/visualization/.

## Authoring pages

- Pages are `.mdx` files under `docs/src/content/docs/`, grouped as `guides/`, `plugins/`, and `migration/`.
- Every page needs `title` and `description` frontmatter. Plugin pages use the component name as the title (e.g. `<MeasureTool />`).
- The sidebar is defined in `docs/astro.config.mjs` — a new page must be added there to appear in navigation.
- Docs describe the public surface. When a change to `src/lib/plugins/<Name>/`, `client/api/`, or `draw/` alters documented behavior, update the matching page in the same change.

## Generated content — never hand-edit

- `docs/src/content/docs/api/*.md` is the Go API reference, generated by `pnpm gen:api` (gomarkdoc) from doc comments in `draw/` and `client/api/`. It is gitignored and regenerated during `pnpm dev` / `pnpm build`. To change it, edit the Go doc comments.
- `docs/public/playground` is also generated and gitignored.
