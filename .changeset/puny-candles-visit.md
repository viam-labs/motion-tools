Replace the three-perf render stats overlay with a draggable Tweakpane pane. It reports FPS, CPU and GPU frame time, draw calls, render passes, triangles, lines, points, geometries, textures, programs, and JS heap, plus a rendering activity waveform showing which animation frames on-demand rendering skips. GPU time and JS heap rows appear only where the browser supports them.
